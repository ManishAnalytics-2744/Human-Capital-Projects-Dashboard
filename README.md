
# Human Capital Projects 2023 – Dashboard

## Project Overview
This project presents an interactive Microsoft Excel dashboard designed to analyze Human Capital Projects for 2023.
The dashboard provides insights into project budgets, completed projects, project risk categories, and project owner-wise budget distribution.                       
## Tools Used
- Microsoft Excel
- Excel Charts
- Data Analysis
- Dashboard Design                                                                                                                                                  
## Dashboard Features

### 1. Project (On Hold) Approved Budget
Visualizes approved budgets for projects currently on hold using a line chart.

### 2. Completed Projects in Qtr4 Budget
Compares completed project budgets across project owners:
- Sneha Verma – 76 Lakhs
- Priya Nair – 98 Lakhs
- Daniel Mathews – 117 Lakhs

### 3. Risk Category of Projects
Analyzes project risk categories:
- High Risk Budget – 598 Lakhs
- Low Risk Budget – 283 Lakhs

### 4. Project Owner % Distribution
Displays the percentage distribution:
- Sneha Verma – 26%
- Priya Nair – 34%
- Daniel Mathews – 40%

## Key Insights
- Daniel Mathews has the highest completed project budget.
- Priya Nair accounts for 34% of the displayed distribution.
- High Risk projects have a higher total budget than Low Risk projects.
- The dashboard provides a visual overview of project budget allocation and risk categories.
